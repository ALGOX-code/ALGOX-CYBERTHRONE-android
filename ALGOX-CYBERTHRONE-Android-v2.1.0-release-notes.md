# ALGOX-CYBERTHRONE Android v2.1.0

Includes the offline, common ALGOX workflow assistant with four guided contexts and searchable references to the requested security tools. The assistant uses local rules and curated links; it is not a generative model and does not launch tools or scan targets.

## Included
- Searchable directory for Nmap, Metasploit, Wireshark, sqlmap, OWASP ZAP, Hashcat, Strix, PentestGPT, PentAGI, HexStrike AI, Autopsy, The Sleuth Kit, Bulk Extractor, CAINE, SIFT, the ambiguous Zeke/Zeek entry, ClamAV, OpenVAS/Greenbone, YARA, Nikto, OnionScan, the unverified OWASP TorBot attribution, MISP, Ahmia, and SpiderFoot.
- Offline checklists for authorized assessment planning, evidence handling, vulnerability/malware triage, and threat-intelligence review.
- Existing local evidence hash tool and historical reference database.

## Boundaries
The listed external tools and their models, scanners, signatures, and services are not bundled or invoked by ALGOX. Active testing must be limited to systems you own or have written authorization to assess. The dark-web section is a link/reference directory only; ALGOX does not connect to Tor or crawl onion sites.

See the accompanying SHA-256 file to verify the APK download.
