# ALGOX-CYBERTHRONE for Android

Version 2.0.0 Android package. Install only on devices you own or administer.

- Package: `com.algox.cyberthrone`
- APK: `ALGOX-CYBERTHRONE-Android-v2.0.0.apk`
- SHA-256: see the `.sha256` file.
- Release notes are included.

Offline-first cybersecurity reference and utility interface. The local assistant is rules-based, not a substitute for a security professional. Optional threat-feed refresh needs internet access.
